During the 2025 spring semester, I took a class on Data Science taught by Professor Aaron Masino. Through this class, I got the opportunity to complete a semester-long project aimed at developing two models for a binary classification problem. The problem is hosted by PhysioNet as part of the George B. Moody PhysioNet Challenge 2025. My models aimed to use ECG data from patients to determine whether they have Chagas disease. My final report is included in as a PDF in the GitHub.
